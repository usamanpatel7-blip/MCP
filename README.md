# telegram-mcp

MCP-сервер, позволяющий Claude читать посты из Telegram-каналов.

## Два режима

| Режим | Что нужно | Что умеет |
|---|---|---|
| **Публичный** (по умолчанию) | ничего | публичные каналы через веб-превью `t.me/s/<канал>` |
| **Аккаунт** | `api_id`/`api_hash` + сессия | любые каналы, группы и чаты, где состоит ваш аккаунт; список ваших каналов |

Если заданы переменные аккаунта, сервер использует аккаунт; иначе — публичный режим.
В каждом инструменте можно явно выбрать режим параметром `use_account`.

## Инструменты

| Инструмент | Зачем |
|---|---|
| `search_telegram(query, since)` | Поиск по всему доступному Telegram сразу — инструмент для исследований по умолчанию |
| `get_digest(channels, since="24h")` | «Что нового?» — посты из нескольких каналов за период одним вызовом, отсортированы по времени, с ошибками по каждому каналу отдельно |
| `get_channel_posts(channel, limit, since, before_id)` | Лента канала; `since` = `24h`, `7d`, `2w` или `2026-09-01` |
| `search_channel_posts(channel, query)` | Поиск по тексту постов |
| `get_post(link)` | Полный текст поста по ссылке `https://t.me/durov/545` |
| `get_channel_info(channel)` | Название, описание, подписчики, дата последнего поста |
| `list_my_channels()` | Ваши каналы с числом непрочитанных (режим аккаунта) |

Промпт `digest` (в Claude Desktop — через меню «+») делает сводку новостей с группировкой по темам и ссылками на посты.

**Экономия контекста:** по умолчанию посты отдаются компактным текстом и обрезаются (`max_chars`, 600 в дайджесте и 1500 в ленте). Полный текст — через `get_post`, все поля — `format="json"`.

**Каналы по умолчанию:** задайте `TELEGRAM_CHANNELS="durov,telegram,..."`, и вопрос «что нового в моих каналах за неделю?» заработает без перечисления каналов.

Примеры запросов к Claude:
- «Что нового в моих каналах за 3 дня? Сгруппируй по темам»
- «Найди в @durov всё про TON за последний год»
- «Перескажи https://t.me/durov/545»

## Поиск по Telegram по умолчанию

`search_telegram(query)` — один инструмент, который ищет сразу везде:
- в базе знаний изученных авторов (локально, мгновенно);
- в ваших каналах (`TELEGRAM_CHANNELS`), а в режиме аккаунта — во всех ваших подписках;
- в режиме аккаунта ещё и в **глобальном поиске Telegram по всем публичным каналам**
  (у Telegram дневной лимит бесплатных глобальных запросов).

Сервер сообщает Claude, что Telegram — основной источник, и просит вызывать `search_telegram`
вместе с веб-поиском на любые вопросы про опыт, кейсы, мнения и новости, даже без упоминания Telegram.

Это подсказка, а не гарантия: клиенты учитывают инструкции MCP-сервера по-разному.
Чтобы закрепить поведение, добавьте такое правило в свои инструкции для Claude
(Claude Code: `~/.claude/CLAUDE.md`; Claude Desktop / claude.ai: Настройки → Профиль → персональные предпочтения
или инструкции проекта):

> Когда я прошу исследовать тему, спрашиваю мнения, опыт, кейсы, практики или новости — всегда вызывай
> `search_telegram` вместе с веб-поиском, даже если я не упомянул Telegram. Ищи ключевыми словами на
> русском и на английском. Цитируй посты ссылками t.me.

## «Только мякотка»: персональная лента от экспертов

Сценарий: вы подписаны на каналы фаундеров и продактов, а Claude раз в день читает новое,
выкидывает шум и присылает вам в Telegram 0–5 постов, которые действительно стоит прочитать:
суть с конкретикой, как применить и ссылку на оригинал.

Как это устроено:
1. `get_new_posts` отдаёт только то, что вам ещё не показывали (состояние хранится в `~/.telegram-mcp/seen.json`).
   Явный шум — рекламу (`#реклама`, `erid`), розыгрыши, короткие посты и репосты без текста — отсекает код,
   до того как посты увидит модель. К каждому посту добавляется `engagement`: просмотры относительно медианы канала.
2. Claude отбирает посты по вашему **профилю интересов** (`get_interest_profile`).
3. `send_to_me` присылает подборку вам в Telegram.
4. `mark_read` запоминает прочитанное, но только после успешной отправки, иначе посты придут в следующий раз.

### Настройка

1. **Каналы:** `TELEGRAM_CHANNELS="channel1,channel2,..."`.
2. **Бот для доставки:** создайте бота у [@BotFather](https://t.me/BotFather), напишите ему `/start`,
   узнайте свой chat id (например, у [@userinfobot](https://t.me/userinfobot)) и задайте
   `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. В режиме аккаунта без бота подборка придёт в «Избранное».
3. **Профиль интересов:** просто скажите Claude: «Мне интересны юнит-экономика, найм, go-to-market в B2B;
   не нужны анонсы и AI-хайп». Он сохранит профиль через `set_interest_profile`. Профиль можно уточнять по ходу:
   «это было мимо», «больше такого».

### Запуск

Вручную — промпт `essence` (в Claude Desktop — через меню «+») или запрос
«Пришли мне мякотку из моих каналов».

По расписанию, каждый день в 9:00 (cron + Claude Code в неинтерактивном режиме):

```cron
0 9 * * * cd ~/telegram-mcp && claude -p "Используй telegram MCP: выполни промпт essence — отбери мякотку из новых постов и пришли мне в Telegram" --allowedTools "mcp__telegram__*"
```

## Изучить канал эксперта и сделать из него базу знаний

Сценарий: «изучи канал @founder_x и вытащи всё полезное». Claude:
1. `study_channel` скачивает архив за выбранный период (по умолчанию год, до 1200 постов; 2 года умеренного
   канала — около 5 секунд), отсекает шум и ранжирует посты по **резонансу**: насколько пост набрал
   больше просмотров, чем соседние. Сравнение с соседями убирает перекос из-за роста канала и возраста поста.
2. Читает лучшие посты целиком и ищет повторяющиеся темы.
3. Пишет конспект: кто автор, ключевые идеи, фреймворки, цифры и кейсы, спорные тезисы, лучшие посты
   со ссылками — и сохраняет его (`save_channel_notes` → `~/.telegram-mcp/notes/`).

Дальше это работает как ваша **база знаний**:
- `get_channel_notes` — конспекты всех изученных авторов;
- `search_knowledge` — мгновенный офлайн-поиск по сохранённым архивам
  («что мои эксперты писали про ценообразование?»).

Claude проверяет их сам, когда отвечает на вопросы из вашей области или делает исследование,
и ссылается на конкретные посты.

Запуск: промпт `study` (параметры: канал, период, цель — например «готовлюсь к запуску B2B SaaS»)
или просто «Изучи канал @founder_x за год и вытащи максимум пользы».

## Работа в claude.ai и на телефоне (удалённый сервер)

claude.ai и мобильные приложения Claude подключают только серверы, доступные из интернета.
Для этого есть HTTP-режим `telegram-mcp-http`, а также `Dockerfile`, `fly.toml` и `render.yaml`.

**Защита.** Сервер пускает только запросы с секретным токеном `MCP_AUTH_TOKEN` (не короче 32 символов).
Токен — часть адреса коннектора: `https://<ваш-хост>/<MCP_AUTH_TOKEN>/mcp`. Без токена сервер отвечает 404,
в логи токен не пишется. **Кто знает этот адрес, тот читает ваш Telegram** — храните его как пароль.
Если адрес утёк, смените токен (новый токен = новый адрес).

### Вариант A: Fly.io (≈ $2–3 в месяц, данные сохраняются)

```bash
# установить flyctl: https://fly.io/docs/flyctl/install/ ; затем fly auth signup / fly auth login
fly launch --copy-config --no-deploy          # придумайте уникальное имя приложения
fly volumes create data --size 1              # архивы, конспекты, профиль интересов
fly secrets set MCP_AUTH_TOKEN=$(python3 -c "import secrets; print(secrets.token_urlsafe(32))")
fly secrets set TELEGRAM_CHANNELS="channel1,channel2"
# по желанию: режим аккаунта и бот
fly secrets set TELEGRAM_API_ID=... TELEGRAM_API_HASH=... TELEGRAM_SESSION=...
fly secrets set TELEGRAM_BOT_TOKEN=... TELEGRAM_CHAT_ID=...
fly deploy
```

Адрес коннектора: `https://<имя-приложения>.fly.dev/<MCP_AUTH_TOKEN>/mcp`.
Если не сохранили токен — просто задайте новый через `fly secrets set` (старый перестанет работать).

### Вариант B: Render (без командной строки)

New → Blueprint → выберите этот репозиторий. Render сам сгенерирует `MCP_AUTH_TOKEN`
(посмотреть: сервис → Environment) и спросит остальные переменные. Тариф Starter нужен ради диска.
Адрес: `https://<сервис>.onrender.com/<MCP_AUTH_TOKEN>/mcp`.

### Подключение в Claude

claude.ai → Настройки → Коннекторы → «Добавить свой коннектор» → вставьте адрес → Добавить.
Коннектор автоматически появится в мобильном приложении под тем же аккаунтом. Включайте его
в чате через меню инструментов. На тарифах Team/Enterprise добавить коннектор может владелец организации.

### Важно для режима аккаунта

Сделайте для сервера **отдельную сессию**: запустите `telegram-mcp-login` ещё раз, а не копируйте
локальную. Одна сессия, используемая одновременно с двух IP-адресов, может быть сброшена Telegram.
Отозвать доступ сервера можно в любой момент: Telegram → Настройки → Устройства.

## Установка

```bash
git clone <repo> telegram-mcp && cd telegram-mcp
python -m venv .venv && .venv/bin/pip install -e .
```

### Подключение к Claude Code

```bash
claude mcp add telegram -- /абсолютный/путь/telegram-mcp/.venv/bin/telegram-mcp
```

### Подключение к Claude Desktop

`claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "telegram": {
      "command": "/абсолютный/путь/telegram-mcp/.venv/bin/telegram-mcp",
      "env": {
        "TELEGRAM_API_ID": "123456",
        "TELEGRAM_API_HASH": "abcdef...",
        "TELEGRAM_SESSION": "1Aa...",
        "TELEGRAM_CHANNELS": "durov,telegram",
        "TELEGRAM_BOT_TOKEN": "123:ABC...",
        "TELEGRAM_CHAT_ID": "123456789"
      }
    }
  }
}
```

Переменные `TELEGRAM_API_*`/`TELEGRAM_SESSION` нужны только для режима аккаунта; `TELEGRAM_CHANNELS` и бот — для персональной ленты.

## Режим аккаунта

1. Получите `api_id` и `api_hash` на https://my.telegram.org → *API development tools*.
2. Выполните вход (спросит телефон и код из Telegram):
   ```bash
   .venv/bin/telegram-mcp-login
   ```
3. Скопируйте выведенную строку `TELEGRAM_SESSION=...` в конфиг.

⚠️ Строка сессии даёт полный доступ к аккаунту — храните её как пароль. Сервер только читает сообщения.
